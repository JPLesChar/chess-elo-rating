# Chess Elo Rating Calculator
An unofficial calculator for estimating Elo rating changes after a chess game.

Features
Calculates Elo rating changes
Supports both winners and draw results
Simple, responsive interface
No account or installation required
How to Use
Enter both players’ current Elo ratings.
Select the result of the game.

Usage
Open index.html in a web browser or access the hosted GitHub Pages site.

## Privacy & Data Storage

This application stores all data locally in your browser using Local Storage.

No player names, ratings, games, or club data are transmitted to or stored on any server.

Each browser maintains its own independent database.

### Backup Recommendation

Export your data regularly using the **Export Data** feature.

The exported JSON file can be used to:

- Restore your data after a browser reset.
- Transfer your database to another computer.
- Create periodic backups.

### Important

Clearing browser data or changing browsers may remove locally stored information.

Always keep a recent backup of your exported data.

### Disclaimer
This is an unofficial chess Elo calculator and is not affiliated with FIDE or any chess organization. The calculator provides estimates and may not match the rating system used by a specific federation or platform.
